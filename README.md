# PaperPlanePals: A Cartoony +1 Paper Plane Game

PaperPlanePals is a fun and engaging Minecraft plugin that brings the classic +1 paper plane game to life in a cartoony world. Players can start a game, throw paper planes, hatch eggs for money, and interact with various pets. The game features a map with breakable walls that can be destroyed based on the strength of the launch, adding an exciting challenge to the gameplay.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Start the game by typing `/start` in the chat.
2. Throw a paper plane by typing `/throw` in the chat.
3. Hatch an egg for money by typing `/hatch` in the chat.
4. Interact with pets by typing `/pet` in the chat.
